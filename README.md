# ComputerStoreJava

## Overview
ComputerStoreJava is a modular Java application intended to model the domain of a computer store. The project is organised into separate modules for the data-access layer (`DAO`), the service layer (`Service`), and the domain model (`model`). 

## Repository Structure
```
Java/
├── DAO/          # Data-access module (IntelliJ module definition in `DAO.iml`)
├── Service/      # Service layer module (`Service.iml`)
├── model/        # Domain model module (`model.iml`)
├── src/          # Stand-alone module entry point (`Main.java` template)
```

## Getting Started
 **Build & Run** – Use IntelliJ's build tools or run `Main.java` directly.
